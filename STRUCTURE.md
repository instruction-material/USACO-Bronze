# USACO-Bronze Structure

This repository is a problem bank for `USACO Bronze`. Historical folder names
remain, but each active problem now uses the common wrapper shape.

Active public folders stay at the repository top level and contain
`README.md`, `starter/`, and `solution/`. Folders not linked by the live catalog
on 2026-05-14 were moved to `_archived-unlinked/`. That archive is retained as
an optional problem bank and history source, not as the active public course
surface.

Some migrated problems have only one real legacy snapshot; the opposite role
folder contains a README placeholder until a distinct starter or solution is
authored.

When promoting an archived problem, restore it to the top level and update the
live course link in the same change.
